# Weekly progress reports

The PDF academic rules require a `progress-report` directory and weekly evidence recorded in Git history. Reports in this directory must describe observed work only; plans, unverified results, and historical assumptions must not be presented as completed work.

## Naming

Use ISO week names:

```text
YYYY-Www.md
```

Example: `2026-W48.md` covers Monday 23 November through Sunday 29 November 2026.

## Required evidence

Each report should include:

- reporting period;
- repository baseline and verified commit hashes;
- functionality that existed before the week;
- work actually performed during the week;
- exact verification commands and results;
- incomplete work and blockers;
- next-week plan clearly labelled as planned work.

Use [`TEMPLATE.md`](TEMPLATE.md) for future reports. A report file does not replace the requirement to commit real progress at least weekly.
